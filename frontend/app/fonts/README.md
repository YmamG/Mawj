# Saudi heading font

`SaudiWeb-Regular.woff2` and `SaudiWeb-Bold.woff2` are the web font files supplied by the project owner in the uploaded Saudi font archive. Only the WOFF2 font assets are included; desktop fonts, proof HTML and macOS metadata are omitted.

Next.js serves the files locally through `next/font/local`. Arabic h1/h2/h3 headings use Saudi; body copy continues to use Noto Sans Arabic. English typography is unchanged.
