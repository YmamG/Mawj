mawj.

Your thoughts are personal.

Mawj stores your account, journal entries, task details, future goals, optional goal images, settings and uploaded profile photo in its database and file storage. Other users cannot access your records through the application.

Operator access

Django administration is disabled in production. A separate read-only operator page lists usernames and registration dates without email addresses, account content or editing controls. An administrator using Mawj’s interface cannot read another user’s records or sign in as that user. A person who controls the server, code and encryption secret can still technically access data.

{% if e2ee_preview %}

Journal text is encrypted in the browser before storage. After sign-in, the server automatically gives the account session its journal key, so no extra phrase or recovery key is required. This protects text when the database is viewed by itself, but it is not end-to-end encryption and does not hide journals from the server operator. Tasks, goals and some metadata remain outside journal-text encryption. This design has not had an independent security review.

{% else %}

Journals, tasks and goals are not end-to-end encrypted and should not be treated as hidden from the hosting operator.

{% endif %}

Account passwords are stored as hashes, not readable text.

Optional AI processing

Demo mode is a labeled simulation and sends no text to an outside service. If Gemini, OpenAI or Claude is configured, the selected text is sent to that provider when you press the feature button. The server and provider can read it during that request, and the provider’s policy applies.

Sessions and local settings

Essential session and CSRF cookies support sign-in and protect changes. Your theme is stored locally and in your account; interface language is stored locally and in a preference cookie. Mawj includes no advertising or analytics trackers.

Your control

You can edit and delete journal entries, tasks and goals, and remove profile or goal images. Deleting an entry deletes its suggestions; accepted tasks and goals remain until you delete them separately. The site operator manages backups and retention.
